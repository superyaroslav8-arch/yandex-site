# Яндекс — Всё о компании

Полный информационный сайт о Яндексе в тёмном стиле с градиентами и фиолетовым акцентом.

## Что на сайте

- **История** — полный таймлайн развития с 1990 по 2026 год
- **Все сервисы** — кликабельные карточки с прямыми ссылками на официальные сервисы + быстрый поиск
- **Контакты** — адреса, телефоны, почта
- **Вакансии** — направления и ссылки на yandex.ru/jobs

## Как открыть

Просто открой файл `index.html` в браузере или включи GitHub Pages.

## GitHub Pages

Репозиторий готов для GitHub Pages:
1. Settings → Pages
2. Source: Deploy from a branch
3. Branch: `main` / root

Сайт будет доступен по адресу:
`https://superyaroslav8-arch.github.io/yandex-site/`
